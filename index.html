Refinement Operations

  • 1. Create Product ID Column: Renames Member prefix (MB → CPLN, UB → UC) and combines with 'X' + Length (e.g. CPLN10010X280).
  • 2. Remove Duplicate Product IDs: Finds and removes duplicate Product ID entries.
  • 3. Compare with Existing Product List: Compares Product IDs against the uploaded Existing Product List. If a product already exists, it is filtered out—retaining only **New Products** in the final output file: New Product List.xlsx.

Allowed File Formats

  • Cutlist File: Excel (.xlsx, .xls), CSV (.csv), or Text Cutlist (.txt).
  • Existing Product List File: Excel (.xlsx, .xls) or CSV (.csv) containing a Product column (e.g. Products (53) 01.09 - 26.09.xlsx).
